# 📚 Campus Kiosk

A centralized on-campus kiosk system designed to streamline student and faculty tasks such as enrollment, document requests, grade management, and student behavior reporting. The system leverages RFID-based login to securely access personalized functionalities.

---

## 📌 Project Overview

**campus-kiosk** is a smart digital kiosk solution aimed at enhancing campus operations. It serves both **students** and **faculty/staff** by offering essential services through a centralized system placed within school premises. This interactive system minimizes administrative bottlenecks and improves access to academic and administrative services.

---

## 🎯 Key Features

### For Students:
- 🔐 **RFID Login** to securely access their personalized dashboard.
- 📄 **Request Documents** such as transcripts, certifications, and more.
- 📬 **Track Document Status** in real-time.
- 📝 **View Enrollment Status** to stay updated on academic standing.

### For Teachers & Staff:
- 🎓 **Manage Grades**: Add, update, or edit student grades.
- 📘 **Edit Enrollment Details** for students.
- ⚠️ **Report Student Misconduct**: Submit reports for students violating school policies.

---

## 🧩 Technologies Used

- **HTML**, **CSS**, **JavaScript**
- **Firebase** (Authentication, Firestore Database)
- **RFID USB Reader** for secure login integration
